# Hardware Setup

## Supported boards

Any Raspberry Pi Pico variant running CircuitPython:

| Board | USB PID |
|-------|---------|
| Pico W | 0x8058, 0x8120 |
| Pico (non-W) | 0x80F4 |
| Pico 2 | 0x8150 |
| Pico 2 W | 0x8160 |

All use Adafruit VID `0x239A`. Cost: ~$4.

## Automated setup (recommended)

The CLI handles everything — flashing CircuitPython, downloading libraries, and installing firmware:

1. **Hold the BOOTSEL button** on the Pico (the only button on the board)
2. **While holding BOOTSEL**, plug the Pico into your PC with the USB cable
3. Release BOOTSEL. A drive called **RPI-RP2** appears in File Explorer
4. Run:

```bash
pywinhello setup-pico
```

The script will:

- Detect the Pico in bootloader mode (RPI-RP2 drive)
- Download and flash CircuitPython
- Download the `adafruit_hid` USB keyboard library
- Copy the HID bridge firmware (`boot.py`, `code.py`)
- Verify the device responds to PING

### Setup options

```bash
pywinhello setup-pico --drive E:         # specify CIRCUITPY drive manually
pywinhello setup-pico --board pico       # specify board variant explicitly
pywinhello setup-pico --verify-only      # just test if the Pico responds
pywinhello setup-pico --skip-verify      # skip the PING step
```

If the Pico already has CircuitPython (CIRCUITPY drive visible instead of RPI-RP2), the script skips flashing and goes straight to library/firmware installation.

## Manual setup

If the automated script fails (network issues, drive detection problems):

1. **Flash CircuitPython**:
    - Hold BOOTSEL, plug in Pico → `RPI-RP2` drive appears
    - Download the `.uf2` from [circuitpython.org/downloads](https://circuitpython.org/downloads)
    - Copy the `.uf2` to the RPI-RP2 drive → Pico reboots, `CIRCUITPY` appears

2. **Install adafruit_hid**:
    - Download the [Adafruit CircuitPython Bundle](https://github.com/adafruit/Adafruit_CircuitPython_Bundle/releases) (9.x-mpy zip)
    - Extract and copy `lib/adafruit_hid/` to `CIRCUITPY/lib/adafruit_hid/`

3. **Copy firmware**:
    - The firmware files are bundled in the pywinhello package
    - Find them at `pywinhello/_data/firmware/` in your site-packages
    - Copy `boot.py` and `code.py` to `CIRCUITPY/`

After setup, your CIRCUITPY drive should look like:

```
CIRCUITPY/
├── boot.py
├── code.py
├── boot_out.txt          (auto-generated by CircuitPython)
└── lib/
    └── adafruit_hid/
        ├── __init__.mpy
        ├── keyboard.mpy
        ├── keyboard_layout_us.mpy
        ├── keycode.mpy
        └── ...
```

## Verify

```bash
pywinhello ping
# PONG from COM8
```

## Serial protocol

The Pico communicates via CDC serial (text, newline-delimited, 115200 baud):

| Command | Response | Description |
|---------|----------|-------------|
| `PING` | `PONG` | Health check |
| `TYPE:1234` | `OK` | Type characters |
| `PRESS:ENTER` | `OK` | Press named key |
| `COMBO:CTRL+C` | `OK` | Key combination |
| `DELAY:100` | `OK` | Set inter-key delay (ms) |

## Two CDC ports

`boot.py` enables two CDC channels: console (REPL, lower COM#) and data (higher COM#). The host library auto-detects the data port by picking the highest-numbered COM port among VID:PID matches.

## Troubleshooting

**"CIRCUITPY drive not found"**
: CircuitPython isn't installed. Hold BOOTSEL, plug in, and run `pywinhello setup-pico`.

**"Pico not found" during ping**
: The serial port isn't detected. Open Device Manager → Ports (COM & LPT) and look for the COM port number.

**RPI-RP2 drive doesn't appear**
: Try a different USB cable. Charge-only cables don't expose the drive.

**CIRCUITPY drive doesn't appear after flashing**
: Wait 10-15 seconds. If nothing happens, unplug, hold BOOTSEL, plug back in, and try again.

**PIN entry types wrong characters**
: The firmware uses US keyboard layout. PIN digits (0-9) are unaffected by keyboard layout.

**Two COM ports in Device Manager**
: Normal. The lower-numbered one is the REPL (for debugging). The higher-numbered one is the data channel (used automatically).
